# Original math subsystem port

This module compiles selected **verbatim original function bodies** from the
uploaded Pikmin 2 decompilation, not a replacement imitation of game logic:

- Dolphin `C_MTXLookAt`, `C_MTXPerspective`, `C_MTXOrtho`.
- Game `qdist2`, `roundAng`, `angDist` from `src/sysCommonU/sysMath.cpp`.

`original_math.c` is generated by `extract_upstream.py`; `provenance.json` records
the original source files and extracted functions' SHA-256 hashes. The uploaded
source files are not edited. Run `python3 game_math/extract_upstream.py --check`
from `port3ds/` to check that the extracts still match the supplied source.

`math_compat.h` contains narrow float/vector/matrix types and the original math
constants. `port_math.c` implements scalar ARM equivalents of the paired-single
vector normalize/cross operations needed by the original camera routine.
The original `__frsqrte` estimate is replaced with `1/sqrtf`; numerical results
are functionally close but not bit-identical to GameCube instructions.

`port_math_camera` validates the camera, then executes original `C_MTXLookAt`.
`port_math_distance_xz` and `port_math_turn_toward` execute the original game
distance/angle routines. The wrappers explicitly handle invalid input and
degenerate cameras rather than letting unsupported PowerPC routines become
empty functions.

`port_math_concat` is an alias-safe scalar translation of the original PowerPC
`PSMTXConcat` matrix multiplication semantics. Upstream `C_MTXConcat` is empty,
so this adapter is explicitly new portability code, not an original C extract.

Projection routines retain the GameCube normalized-depth range `[-1,0]`.
They cannot be passed blindly to PICA200. Use the camera matrix with a native
3DS projection, or adapt depth/viewport conventions explicitly.

## Build

Compile **both** `game_math/original_math.c` and `game_math/port_math.c` as C11
with `-Iinclude -Igame_math -ffp-contract=off` and link `-lm`.
The public C/C++ API is `include/port_math.h`. Functions contain no libctru
dependencies and are testable on the host:

```sh
cc -std=c11 -Wall -Wextra -Werror -ffp-contract=off -Iinclude -Igame_math \
  game_math/original_math.c game_math/port_math.c tests/math_test.c -lm -o /tmp/math_test
/tmp/math_test
python3 game_math/extract_upstream.py --check
```

This ports SDK/game math used by camera and movement harnesses. It does **not**
port Pikmin entity classes, AI, the complete graphics API or a level loader.
